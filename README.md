- **Tech Stack**: **Angular 20**, **TypeScript**, **Supabase**, **Google Generative AI**, **RxJS**, **Quill Editor**, **Bootstrap Icons**
- **Key Features**:

  - 💻 Progressive Web App (Service Worker)
- **Status**: Active development • Live deployment
